### 2. 中转通道（4 个公开 CORS 反代，轮询使用）

直连 `web.archive.org` 在当前网络环境下不通，故经公开反代中转。
轮询规则：`NODES[i % 4]`，逐篇轮换。

| 代号 | 模板 | 占位符 |
|---|---|---|
| `allallow` | `https://allallow.pages.dev/?url={enc}&mode=full` | `{enc}` = 整条快照 URL 的 URL-encode |
| `nocors` | `https://nocors.pages.dev/proxy?url={enc}` | 同上 |
| `fdgally` | `https://fd-gally.netlify.app/proxy/{raw}` | `{raw}` = 未编码的整条快照 URL |
| `corshttp` | `https://cors-http.netlify.app/.netlify/functions/api?url={enc}` | 同 `{enc}` |

> 部分节点会以 JSON 信封 `{"content": "..."}` 返回页面，解析器已统一解包
> （`wayback_resume.unwrap_delivered`），字节级校验亦已适配。
