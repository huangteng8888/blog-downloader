## 六、数据质量问题（本次实测新发现）

### 6.1 正文图片全部丢失（重要）

- `posts/*.md` 中 **2,404 篇全部不含任何图片引用**（无 `![]()`、无 `<img>`、无 `sinaimg.cn` 链接）。
- `index.json` 的 `images_count` 字段分布极不自然：9 张 = 1,414 篇、10 张 = 878 篇、11 张 = 63 篇……合计声称 22,762 张图，**与正文实际 0 张矛盾**。
- 结论：该字段是抓取阶段的模板计数产物（疑似存在计数上限），**不可作为图片统计依据**；正文图片在 wu2198 这批数据中未保留，需重新抓取或用 archive.org 快照补齐。
