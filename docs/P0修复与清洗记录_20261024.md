## 4. 关键教训（务必保留）

### 4.1 不能用 `style="display:none"` 判断隐藏元素

新浪旧模板会把**真实正文**包在隐藏容器里：

```html
<div style="DISPLAY: none" align="left"> 新华网东京2月9日电 （记者 刘浩远 刘赞）…</div>
```

按 `display:none` 过滤会**整段删除正文**（该样本从 1062 字掉到 422 字）。
因此终版规则只保留有实证的 `class="…invisible"` / `id="reference"`，
并附加 **`MAX_HIDDEN_TEXT = 120`：隐藏块内文本超过 120 字时视为正文容器，予以保留**。

### 4.2 终止锚点不能用 class 通配

`class="…invisible"` 之类的通配锚点可能出现在正文**之前**（导航、按钮），
一旦命中会截掉其后全部内容。终版只保留两个确定性 ID 锚点。

### 4.3 曾被误列的危险 ID

`id="sina_keyword_ad_area2"` 同时出现在 `OPEN_PATS`（**正文容器**）中，
绝不可当作"广告区"删除或终止。

### 4.4 双进程事故

重启时发现 **两个抓取进程并存**：`18328`（11:44 启动，运行旧解析器）与 `9388`（13:01 启动，新解析器）。
旧进程会持续产出污染产物且与新进程重复请求，已终止。**重启抓取前必须先枚举同名进程**：

```powershell
Get-CimInstance Win32_Process -Filter "name='python.exe'" |
  Where-Object { $_.CommandLine -like '*wayback_resume*' } |
  Select-Object ProcessId,CreationDate
```
